# Craftable Creatures

Мод добавляет предметы и 2 прибора с гуи, с помощью которых можно создать яйцо призыва в выживании.

Тут вы можете посмотреть, как я сделал гуи, tileentity, нетворкинг и обычные блоки и предметы
